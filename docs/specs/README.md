# Specs — Features antes de código

Cada feature tiene un spec aquí **antes** de que se escriba código.

| Plataforma | Carpeta | Board |
|---|---|---|
| API / Angular admin / sitio público | [[web/README\|specs/web/]] | [[BOARD-specs-web]] |
| Flutter móvil | [[mobile/README\|specs/mobile/]] | [[BOARD-specs-mobile]] |

## Crear un spec

```
/spec-new <nombre-de-la-feature>
```

Pregunta la plataforma y genera el archivo con numeración independiente por plataforma.
